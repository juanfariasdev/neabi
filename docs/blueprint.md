# **App Name**: NEABI

## Core Features:

- Hero Section: A compelling opening section with a powerful headline about educational transformation and racial equity, featuring a warm background image overlay of diverse community and cultural celebrations, paired with a prominent call to action button directing visitors to explore programs or learn more about NEABI's mission.
- Navigation System: Sticky navigation bar that remains visible while scrolling, containing clear sections for Home, About, Programs, Research, Events, and Blog, with a search icon for easy content discovery and a hamburger menu icon that appears on mobile devices.
- Four Pillars Display: Elegant cards arranged in a responsive grid showcasing NEABI's core work areas: Education (promoting antiracist teaching practices), Research (advancing knowledge on ethnic-racial relations), Extension (community engagement and outreach), and Community (building inclusive spaces for dialogue and growth).
- Statistics Section: Eye-catching display of impactful numbers including "100+ NEABIs Nationwide," "66 Years of History," "10,000+ Students Supported," and "40+ Research Publications" with smooth counter animations that trigger when the section enters the viewport.
- Program Carousel: Interactive horizontal slider featuring flagship NEABI programs with high-quality images, program titles, brief descriptions, category tags, and individual "Learn More" links, with navigation arrows and indicator dots for manual browsing.
- Testimonials Section: Rotating testimonials from students and professors sharing their experiences with NEABI, displayed as individual cards with profile images, quotes, names, institutional affiliations, and roles, conveying authentic impact and transformation stories.
- Educational Resources Hub: Curated collection of antiracist educational materials and teaching resources organized by audience (K-12, Higher Education, Educators, Community Members), with filtering capabilities, descriptions, external links to original sources, and recommendation indicators for varying audience levels.
- Blog/News Section: Grid layout displaying recent articles, announcements, and event updates with thumbnail images, publication dates, category tags, preview text, and "Read More" links, searchable and filterable by topic.
- Events Calendar: Dedicated section showcasing upcoming NEABI events including Semana da Consciência Negra activities, workshops, seminars, and community gatherings with date, time, location, brief description, and registration links.
- Contact Form & Inquiry System: User-friendly submission form for inquiries with fields for name, email, subject, and message, form validation, success/error feedback messages, and backend integration to store submissions in a database for follow-up communication.
- Footer Navigation: Comprehensive footer organized into logical sections (About NEABI, Programs & Resources, Institutional Links, Social Media & Contacts) containing navigation links, institutional information, office hours, social media icons linking to Instagram, Facebook, WhatsApp, and Twitter, plus copyright information.

## Style Guidelines:

- Primary Color: African gold (#D4AF37) used for buttons, links, headings, and key interactive elements to represent value and cultural richness.
- Background Colors: Deep black (#1a1a1a) for dark mode sections and text, warm white (#f8f7f4) as primary background for contrast and readability.
- Complementary Colors: Terra red (#8B4513) for borders, alerts, and secondary highlights representing earthiness and ancestral connection; forest green (#2d5016) for success states, call-to-action buttons, and nature-inspired elements representing Indigenous connection and sustainability.
- Neutral Accents: Light gray (#e8e8e8) for borders and dividers, medium gray (#a0a0a0) for secondary text and captions.
- Status Colors: Success (#27ae60) for confirmations, error (#c0392b) for issues, warning (#f39c12) for alerts, info (#3498db) for notifications.
- Headline Font: 'Playfair Display' (serif, Google Fonts) at 48px desktop / 32px mobile for H1, 36px desktop / 24px mobile for H2, 28px desktop / 20px mobile for H3, using bold weight (700) for maximum impact and sophistication.
- Body Font: 'Inter' (sans-serif, Google Fonts) at 16px desktop / 14px mobile, regular weight (400) for paragraphs with 1.6 line-height for optimal readability and accessibility.
- Accent Font: 'Montserrat' (sans-serif, Google Fonts) at 18-24px for subtitles, featured quotes, and call-to-action text, using bold weight (700) for emphasis.
- Subtle integration of African patterns (Adinkras, kente-inspired designs) and Indigenous geometric motifs (triangles, circles, repeating shapes) as background textures, decorative elements, or card borders throughout the site without overwhelming the content.
- Custom SVG icon set in 24px, 32px, and 48px sizes using 2px stroke weight, styled in primary colors with consistent visual language across all sections.
- Card Design: 8px border-radius, subtle box-shadow (0 2px 8px rgba(0,0,0,0.1)), white background (#f8f7f4) with hover effects that elevate the shadow and shift accent colors.
- Imagery: High-quality photographs featuring genuine community representation with diverse people of different ethnicities, ages, genders, and abilities in authentic educational and cultural settings, avoiding stock photography stereotypes.
- Mobile-First Approach: Design optimized for 320px minimum width with progressive enhancement for larger screens.
- Breakpoints: 320px (mobile), 768px (tablet), 1024px (desktop), 1440px (large desktop) with fluid layouts and flexible components.
- Hamburger Menu: Collapsed navigation menu activated on screens below 1024px, sliding in from the right with 200ms animation, featuring a semi-transparent overlay.
- Fluid Typography: Text sizes scale proportionally between breakpoints for optimal reading experience across all devices.
- Touch-Friendly: Interactive elements minimum 44x44px size for comfortable mobile interaction, adequate spacing between clickable items.
- Smooth Scroll Animations: Elements fade in or slide into view as users scroll, triggering at 200px before entering viewport with 600ms animation duration for fluid, non-jarring transitions.
- Hover States: Buttons change background color and elevation with 200ms transition, links change color to accent gold, cards gain shadow and slight scale increase (1.02x).
- Active States: Current navigation item highlighted in accent gold, form fields with focus state show gold border (2px) and subtle shadow.
- Loading States: Skeleton screens for dynamic content, spinner animations during form submission, success confirmations with checkmark icons.
- Minimum contrast ratio 4.5:1 for normal text, 3:1 for large text, verified with automated tools.
- Keyboard Navigation: All interactive elements accessible via Tab key with visible focus indicators, proper heading hierarchy (H1 > H2 > H3), semantic HTML structure.
- Alt Text: Descriptive alternative text for all images, decorative images marked as such, complex images with detailed descriptions.
- All inputs paired with explicit labels, error messages linked to fields, success messages announced to screen readers.
- "Skip to main content" link available for keyboard users to bypass repetitive navigation.
